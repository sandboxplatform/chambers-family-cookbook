# Real photos

Drop a photo of the finished dish here, named after the recipe's id, and it replaces the AI picture for everyone once the site redeploys (a minute or two).

- Name: `<recipe-id>.jpg` (also `.jpeg`, `.png` or `.webp`). The id is the end of the recipe's web address, e.g. `#r-nannies-bread` → `nannies-bread.jpg`.
- The "Add a real photo" button on each recipe downloads the photo with the right name already, shrunk to a sensible size.
- To upload on GitHub: open this folder, choose **Add file → Upload files**, drop the photo in and commit.
